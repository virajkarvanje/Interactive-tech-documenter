# 🚀 Interactive Tech Documenter & Selection Logic Portal

A modern, responsive dark-themed developer cheat sheet and interactive workspace built during my first semester of Computer Science Engineering. This standalone documentation portal acts as a technical knowledge base and showcases core engineering prerequisites.

## 📱 Live Deployment
[🔗 Click here to view the operational live link!](https://github.io)

## 🛠️ Built With
*   **Semantic HTML5** - Structural layout definitions and document tags (`<main>`, `<nav>`, `<section>`).
*   **Modern CSS3** - Customized midnight palette, structural layout engines (`display: flex`), sticky navigation parameters, and glowing code card blocks.
*   **Vanilla JavaScript** - Logical algorithm processing for real-time validation execution.

## 🌟 Key Features
*   **Developer Profile Block:** Clean card overview highlighting student tracking credentials, engineering branch, and current semester goals.
*   **Sticky Side Navigation:** Responsive side menu panel utilizing smooth-scrolling behavior (`scroll-behavior: smooth`) to seamlessly jump across topics without abrupt page jumps.
*   **Technical Reference Cards:** Monospaced monocolor boxes (`<code>`, `<pre>`) presenting organized code frameworks for HTML basics, CSS resets, and Git workflows.
*   **C++ Language Blueprint:** Clean programming blueprint displaying standard conditional branching configurations (`if-else` selection logic blocks).
*   **Interactive Evaluation Engine:** An integrated, fully operational user widget running the exact modulo logic algorithm (`num % 2 === 0`) to dynamically check if an input number is even or odd in real-time.
